# CustomLazyTNT

Плагин для Paper 1.21.11 от Lazzyibyt

## Возможности

* Осколочный динамит взрывается как обычный TNT и дополнительно ломает обсидиан
* Плачущий обсидиан после взрыва становится обычным обсидианом
* Снежный динамит делает сферу из временного льда
* Воздух и вода заменяются льдом на пять секунд
* Разрушительный динамит ломает блоки и наносит большой урон
* У каждого TNT свой таймер
* Есть снежная кисть по типу brush
* Все типы настраиваются в config.yml

## Как работает поджигание

Кастомный TNT сначала ставится как обычный блок и сам не начинает таймер

Чтобы его зажечь используй

* огниво
* огненный заряд
* редстоун

После поджигания блок превращается в зажженный TNT и начинается таймер из конфига

## Установка

1. Скачай `CustomLazyTNT-1.0.0.jar`
2. Положи его в папку `plugins`
3. Запусти сервер один раз
4. Настрой `plugins/CustomLazyTNT/config.yml`
5. Выполни `/customlazytnt reload`

## Команды

`/customlazytnt give <игрок> <fragment|snow|destructive> <количество>`

`/customlazytnt list`

`/customlazytnt reload`

`/customlazytnt wand`

## Права

* `customlazytnt.admin`
* `customlazytnt.use.fragment`
* `customlazytnt.use.snow`
* `customlazytnt.use.destructive`
* `customlazytnt.wand`

## Снежная кисть

Выдай ее командой `/customlazytnt wand`

ПКМ по блоку создает временную ледяную сферу

Кисть заменяет только воздух и воду

Если временный лед сломать другим взрывом или игроком он не вернется
